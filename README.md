# Ultra-angular multiplexing paper calculations

This repository contains a self-contained implementation of the calculations behind the paper data for `N=2`, `N=4`, `N=8`, and the `11 x 11 = 121` angular grid.

## What to run

- `run_sweep.py`: the one-dimensional `N=2,4,8` sweep used for the sweep data associated with Fig. 2.
- `run_grid_121.py`: the 121-channel calculation used by Fig. 4.
- `core_angular.py` and `field_propagation.py`: the calculation engine and its previously external propagation dependency.
- `targets/`: the exact `0.bmp` through `120.bmp` target images required by the calculations.
- `paper_figures/`: the `Fig2_8.py` and `Fig4.py` post-processing scripts that document how the paper figures consume the calculated results.
- `reference_data/`: the small auxiliary MAT files used by the non-field panels of `Fig2_8.py`.

Large calculated MAT files are intentionally not included because the complete sweep file can exceed GitHub's normal 100 MB per-file limit. They are regenerated by the commands below.

## Environment

The archived calculations were checked with Python 3.11, PyTorch 2.2.0, and an NVIDIA RTX 3090. Install a CUDA-compatible PyTorch build for practical runtimes, then install the remaining packages in `requirements.txt`. OpenCV is pinned to the last release line that is compatible with the archived NumPy 1.26 environment.

The original project uses the Conda environment `torch_env`. For example:

```powershell
conda run -n torch_env python run_sweep.py
```

## Paper calculations

Run the complete `N=2,4,8` sweep:

```powershell
python run_sweep.py
```

Run the 121-channel grid:

```powershell
python run_grid_121.py
```

Both commands refuse to replace an existing output unless `--overwrite` is explicitly supplied. Defaults reproduce the archived paper parameter sets; `--train-steps` and `--nx` are exposed only for quick smoke tests and should remain at their defaults for numerical comparison.

By default, outputs are written under `results/`, which is excluded from version control to keep the repository lightweight.
